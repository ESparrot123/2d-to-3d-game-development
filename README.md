# 2D to 3D Game Development

## About the Project

This project was developed as part of my internship at Hope Foundation.
The project focused on game development using Python and related libraries.

## Technologies Used

- Python
- Pygame
- PyOpenGL
- OBJ Loader

## Project Features

- Player movement
- Asteroids and obstacles
- Collision detection
- Explosion effects
- Power-ups
- Shield functionality
- Weapons
- Score tracking
- Background effects
- Sprite and spritesheet handling

## Project Files

The project contains Python modules for:

- Player/ship
- Asteroids
- Weapons
- Power-ups
- Shield
- Game scenes
- Background
- Collision/entity handling
- Sprites and spritesheets
- Game utilities
