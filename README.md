# 2D to 3D Game Development

## About the Project

This project involved transforming a 2D game concept into a 3D endless-runner style game.

## Technologies Used

- Python
- PyOpenGL
- Pygame
- OBJ Loader

## Features

- Player movement
- Obstacles
- Collision detection
- Score tracking
- 3D game environment
